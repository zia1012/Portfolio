# Content writing

## Voice

First person, plain, specific. Short sentences. Show what was built and what changed because of it.
Avoid filler words like "passionate", "innovative", "cutting-edge", "rockstar", "ninja".

## Hero

- One line: name and role. One line: what you do and for whom.
- One primary call to action (View projects) and one secondary (Contact or Resume).

## About

80–150 words. Who you are, what you work on, what you are looking for. Optional single personal line.

## Project case study shape

Each project file has these fields:

- `title`, `slug`, `summary` (one sentence, ≤ 160 chars), `tags`, `year`
- `role` — what you personally did
- `problem` — what needed solving, 1–3 sentences
- `approach` — key decisions and why, 3–5 bullets
- `outcome` — result, with a number only if the user gave one
- `links` — live demo, source code (omit if none)
- `image` + `imageAlt`

## Experience entries

`company`, `role`, `start`, `end` (or "Present"), 2–4 bullets starting with a verb.

## Facts

Never invent employers, dates, metrics, clients, or links. Unknown → `TODO: <what is needed>`.

## Meta descriptions

150–160 characters, unique per page, describe the page content.
